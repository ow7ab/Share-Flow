# Share Flow

### Fast. Secure. Seamless. Share Without Limits.

**Share Flow** is a modern Android file-sharing and device-transfer application designed to make sharing files between devices simple, fast, and reliable.

Built with an offline-first approach, Share Flow enables direct file transfers between connected devices over a local Wi-Fi network, without depending on internet connectivity, cloud storage, or external file-sharing services.

The application combines file sharing, device migration, file management, and media browsing in one integrated experience.

---

## 🇬🇧 English

### What is Share Flow?

Share Flow is an Android application designed to simplify file sharing and data transfer between devices.

It establishes a direct local connection between devices using a QR-based pairing system. Once connected, users transfer files directly over the local network without uploading their data to external servers.

Whether you want to share photos, videos, music, documents, folders, or Android applications, Share Flow provides a unified and intuitive experience.

### Key Features

- **Offline File Sharing:** Transfer files between devices without requiring an internet connection.
- **QR Code Connection:** Connect devices using dynamically generated QR codes.
- **Fast Local Transfers:** Transfer files directly over a local Wi-Fi network.
- **Multiple File Types:** Share images, videos, audio, documents, archives, folders, and APK files.
- **Application Sharing:** Share Android application installation packages.
- **Transfer Management:** Monitor transfer progress, pause or cancel supported transfers, and resume interrupted transfers.
- **File Integrity Verification:** SHA-256 verification to help ensure transferred files remain intact.
- **Transfer History:** Keep track of previous file-sharing operations.
- **Built-in File Manager:** Browse and organize files directly within the application.
- **Media Gallery:** Browse images and videos using an integrated media interface.
- **Private Vault:** Keep selected files in a private storage area.
- **Device Migration:** Simplify transferring personal files when moving to another device.
- **Storage Management:** Access tools for compression, duplicate-file management, and storage organization.
- **Bilingual Interface:** Supports Arabic and English with RTL and LTR layouts.

### How It Works

1. Open Share Flow on both Android devices.
2. Select the receiving device and create a connection session.
3. Scan the generated QR code using the sending device.
4. Approve the required Wi-Fi connection permissions.
5. Establish a direct local connection between the devices.
6. Select the files you want to share.
7. Start transferring and monitor the progress.

Your files travel directly between the connected devices through the local network.

## 🇸🇩 العربية

### ما هو تطبيق Share Flow؟

Share Flow هو تطبيق أندرويد متكامل لمشاركة الملفات ونقل البيانات بين الأجهزة، صُمم لتوفير تجربة سريعة وسهلة وآمنة لنقل الملفات دون الحاجة إلى الإنترنت.

يعتمد التطبيق على إنشاء اتصال مباشر بين الأجهزة عبر شبكة Wi-Fi محلية، باستخدام نظام اقتران ذكي يعتمد على رموز QR الديناميكية.

يتيح التطبيق إرسال واستقبال مختلف أنواع الملفات، بما في ذلك الصور والفيديوهات والمستندات والمجلدات والتطبيقات، دون الحاجة إلى رفعها إلى خدمات تخزين سحابية أو خوادم خارجية.

### المميزات الرئيسية

- **المشاركة دون إنترنت:** نقل الملفات مباشرة بين الأجهزة دون الحاجة إلى اتصال بالإنترنت.
- **الاتصال عبر QR:** ربط الأجهزة بسهولة باستخدام رموز QR يتم إنشاؤها ديناميكياً.
- **سرعة نقل الملفات:** الاستفادة من الاتصال المحلي عبر Wi-Fi لنقل البيانات مباشرة.
- **دعم مختلف الملفات:** إرسال واستقبال الصور والفيديوهات والصوتيات والمستندات والملفات المضغوطة والمجلدات.
- **مشاركة التطبيقات:** إرسال ملفات APK الخاصة بتطبيقات أندرويد ومشاركتها بغرض التثبيت.
- **إدارة عمليات النقل:** متابعة تقدم الإرسال والاستقبال، وإيقاف العمليات المدعومة أو استكمال النقل عند انقطاعه.
- **التحقق من سلامة الملفات:** استخدام SHA-256 للمساعدة في التأكد من سلامة الملفات بعد النقل.
- **سجل العمليات:** الاحتفاظ بسجل لعمليات الإرسال والاستقبال السابقة.
- **مدير الملفات:** تصفح الملفات وإدارتها من داخل التطبيق.
- **معرض الوسائط:** استعراض الصور والفيديوهات من خلال واجهة مدمجة تشبه تطبيقات المعرض.
- **الخزنة الخاصة:** حفظ الملفات المختارة داخل مساحة تخزين خاصة.
- **نقل بيانات الجهاز:** تسهيل نقل الملفات الشخصية عند الانتقال إلى هاتف جديد.
- **إدارة مساحة التخزين:** أدوات لتنظيم الملفات وضغطها واكتشاف الملفات المكررة.
- **دعم اللغتين:** واجهة عربية وإنجليزية مع دعم اتجاهي RTL وLTR.

### كيف يعمل التطبيق؟

1. افتح Share Flow على جهازي أندرويد.
2. اختر جهاز الاستقبال وأنشئ جلسة اتصال.
3. امسح رمز QR باستخدام جهاز الإرسال.
4. وافق على أذونات الاتصال بشبكة Wi-Fi المطلوبة.
5. يتم إنشاء اتصال محلي مباشر بين الجهازين.
6. حدد الملفات التي تريد إرسالها.
7. ابدأ عملية النقل وتابع تقدمها حتى اكتمالها.

تنتقل الملفات مباشرة بين الأجهزة المتصلة دون الحاجة إلى رفعها إلى الإنترنت.
